# 접힘·펼침 화면 레이아웃

- 본문과 고정 하단 메뉴는 사용 가능한 화면 폭 전체를 채운다. 기존 448px 최대 폭 제한은 두 영역 모두 적용하지 않는다.
- 기기 이름을 감지하지 않고 실제 브라우저 창 폭을 사용하므로, 앱을 열어 둔 채 접거나 펼쳐도 새로고침 없이 크기가 바뀐다. 분할 화면에서도 동일하다.
- 페이지 안쪽 여백, 요약 카드의 2열 구성, 글자 크기와 447px 이하의 작은 화면 글자 보정은 기존대로 유지한다.
- 예산 계산·데이터 저장 동작은 변경하지 않는다.

## 확인 방법

`npm run dev -- --host 127.0.0.1`로 실행하고 브라우저 창 폭을 320, 360, 390, 448, 600, 768, 840, 1153px로 바꿔 확인한다.

1. 모든 폭에서 본문과 하단 메뉴가 창 폭과 일치하고 좌우로 넘치지 않아야 한다.
2. 448px 이하에서는 변경 전과 카드 크기·여백·글자 크기가 같아야 한다.
3. 넓은 화면에서 접힌 폭으로 줄였다 다시 넓혀도 내용·선택 상태가 유지되어야 한다.
4. 긴 메모의 입력창 높이가 폭에 맞게 다시 계산되고, 아래 콘텐츠와 겹치지 않아야 한다.

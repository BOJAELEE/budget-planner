# 월별 메모

- 메모 카드는 기존처럼 대시보드 맨 위의 청구월 제목과 선택창 사이에 표시한다. 핵심 자금 요약은 청구월 선택창 아래에 배치하며, 메모 내용은 접지 않고 그대로 표시한다.
- 선택한 **청구월**별로 저장하며, 수입·고정비의 전월 적용 규칙과는 별개이다.
- `메모 쓰기` 또는 `수정`으로 입력하고 `저장`을 누른다. 취소하면 저장된 내용을 유지한다.
- 입력 중에도, 저장 후에도 줄 수와 화면 폭에 따라 높이가 늘어난다. 아래 콘텐츠는 자연스럽게 내려간다.
- 메모는 최대 10,000자이며 HTML이 아닌 일반 텍스트로 표시한다.
- 백업 v9는 메모를 포함한다. 메모 필드가 없는 구버전 백업을 복원하면 현재 메모는 보존한다.

## 배포 순서

1. `supabase/migrations/20261009044024_add_monthly_memos.sql`을 기존 프로젝트에 적용한다.
2. 앱을 기존 GitHub Pages 경로로 배포한다.
3. 메모 저장·새로고침·청구월 전환을 확인한다.

기존 금융 테이블과 계산은 변경하지 않는다. 새 테이블은 기존 로그인 없는 공유 접근 정책을 유지하므로 민감한 인증정보는 메모에 기록하지 않는다.
앱만 이전 버전으로 되돌려도 금융 기능은 유지된다. 되돌릴 때 메모 테이블을 삭제하지 않는다.

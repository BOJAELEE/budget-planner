# 대시보드 계산 기준

- 청구월의 예상 카드값은 전월 고정비의 카드별 기준 금액과 청구월 추가지출의 합계입니다.
- 실제 카드값을 입력한 카드는 그 금액을 사용하고, 미입력 카드는 예상 카드값을 사용합니다. 대시보드는 예상/실제 버튼으로 한 번에 하나의 계산 결과를 표시하며, 처음에는 예상이 선택됩니다.
- 각 결과의 총필요 예산은 전월 현금이체 고정비와 해당 카드값 합계입니다. 부족금액은 `max(총필요 예산 - 전월 수입, 0)`입니다.
- 여유 자금의 월 기준액은 `전월 수입 − 전월 활성 고정비 전체 + 150,000원`입니다. 현금이체와 카드 고정금액을 모두 고정비에 포함합니다.
- 여유 자금 사용액은 `총필요 예산 − 전월 활성 고정비 전체`입니다. 예상·실제 카드값에 따라 각각 계산하며, 사용 후 잔액은 `여유 자금 기준액 − 사용액`입니다. 실제 카드값이 고정 카드 기준보다 낮으면 사용액은 음수로 표시되어 남는 금액에 반영됩니다.
- 여유 자금 사용 후 잔액이 음수일 때 그 부족분을 매 청구월 별도로 적용되는 비상금 500,000원에서 최대 500,000원까지 충당합니다. 사용하지 않은 비상금 한도는 다음 달로 이월하지 않습니다.
- 남은 부족분만 월급통장 → 비상금통장 → 여행통장 잔고에서 차감합니다. 그래도 남으면 미충당 금액으로 표시합니다.
- 저장된 통장 잔고를 비상금 500,000원으로 덮어쓰지 않습니다. 이후 월로 이월되는 통장 잔고는 실제 카드값(미입력분은 예상값) 기준 계산 결과만 사용합니다. 예상 카드값 대시보드는 비교용이며 저장 잔고에 영향을 주지 않습니다.

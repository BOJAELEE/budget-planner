# 대시보드 계산 기준

- 대시보드·추가지출·히스토리는 고정비·수입과 같은 **기준월**(예: 11월 사용·12월 1일 카드결제분은 `2026년 11월`로 표시)로 통일해 표시하며, 매월 2일에 다음 달로 전환합니다(결제일 당일인 1일까지는 직전 월 유지). 단, 기존 데이터와 백업 호환을 위해 `extra_spendings`·`monthly_card_actuals`·`monthly_memos` 및 브라우저 `dashboardScenarioViews`의 내부 저장 키는 기존 다음 달 카드 청구월(`YYYY-MM`)을 그대로 사용합니다.
- 청구월의 예상 카드값은 전월 고정비의 카드별 기준 금액과 청구월 미완료 추가지출의 합계입니다. `결재완` 표시한 기록은 목록과 백업에 남지만 추가지출 합계·예상 카드값·히스토리에서 제외되며, `완료 취소` 시 다시 포함됩니다.
- 실제 카드값을 입력한 카드는 그 금액을 사용하고, 미입력 카드는 예상 카드값을 사용합니다. 대시보드는 예상/실제 버튼으로 한 번에 하나의 계산 결과를 표시합니다.
- 예상/실제 선택은 연도·청구월별로 독립적으로 기억합니다. 선택 이력이 없는 달은 실제 카드값 입력 여부와 무관하게 항상 예상으로 시작하며, 다른 달의 선택을 가져오지 않습니다. 직접 실제를 선택한 달만 다시 열 때 실제로 표시됩니다.
- 이 선택은 현재 브라우저에 저장하므로 새로고침·페이지 이동 후에도 유지됩니다. 다른 브라우저·기기로는 동기화하지 않으며 금융 데이터 백업에는 포함하지 않습니다. 브라우저 데이터를 지우면 초기화됩니다. 저장이 차단되거나 저장값이 잘못된 경우에도 대시보드는 동작하며, 저장 실패 시 안내하고 앱을 열어 둔 동안에는 월별 선택을 유지합니다. 이 설정은 화면 표시 기준일 뿐 별도 결산 확정 기능이나 금융 데이터 변경이 아닙니다.
- 대시보드 상단에는 예비자금·사용금액·잔액을 한 줄 세 칸의 통합 요약형으로 표시합니다. 수입이 고정비 이상인 달에는 `수입 − 고정비` 여유분을 상단 대시보드에 반영하지 않으므로 `예비자금`은 `650,000원`(`월급 여유 자금 150,000원 + 월간 비상금 500,000원`)으로 유지되고 추가 지출이 곧바로 예비자금에서 차감됩니다. 반대로 `수입 < 고정비`인 달에는 고정비 초과분(`고정비 − 수입`)만큼 예비자금(`월급 여유 자금 → 월간 비상금`)에서 차감됩니다. 사용금액은 `예비자금 − 잔액`으로 초과분을 잘라내지 않고 표시하며, 잔액이 음수이면 마지막 칸의 제목을 `초과금액`으로 바꾸고 음수 금액을 적색으로 표시합니다.
- 각 결과의 총필요 예산은 전월 현금이체 고정비와 해당 카드값 합계입니다. 부족금액은 `max(총필요 예산 - 전월 수입, 0)`이며 하단 정산(`카드결제 이체금`)에서 `수입 − 고정비` 차액을 반영합니다.
- 카드별 예산 표 위의 `실제 월급` 입력 칸은 선택된 기준월의 `수입` 페이지 `월급` 항목(`monthly_incomes`)과 양방향으로 연동됩니다. 대시보드에서 월급을 수정하면 해당 월의 월급 값만 저장되며(다른 달 고정수입 기본값은 유지), 변경된 `수입` 합계가 `부족금액`과 `카드결제 이체금`의 `옮길 금액 합계`에 즉시 반영됩니다. 월급이 기준 월급(`income_templates`)과 다를 때는 `실제 월급` 카드에 차액(`기준 대비 ±금액`)이, `카드결제 이체금`에는 `월급 변동 반영`(기준 이체금 대비 `덜 옮김` / `더 옮김` / `이체 변동 없음`)이 함께 표시됩니다.
- 여유 자금의 월 기준액은 `min(전월 수입 − 전월 활성 고정비 전체, 0) + 150,000원`입니다. 현금이체와 카드 고정금액을 모두 고정비에 포함하며, 수입 여유분(`수입 > 고정비`)은 상단 여유 자금에 더하지 않고 고정비 초과분(`수입 < 고정비`)만 차감합니다.
- 여유 자금 사용액은 `총필요 예산 − 전월 활성 고정비 전체`입니다. 예상·실제 카드값에 따라 각각 계산하며, 사용 후 잔액은 `여유 자금 기준액 − 사용액`입니다. 실제 카드값이 고정 카드 기준보다 낮으면 사용액은 음수로 표시되어 남는 금액에 반영됩니다.
- 여유 자금 사용 후 잔액이 음수일 때 그 부족분을 매 청구월 별도로 적용되는 비상금 500,000원에서 최대 500,000원까지 충당합니다. 사용하지 않은 비상금 한도는 다음 달로 이월하지 않습니다.
- 예산 그래프의 전체 가용액은 `min(전월 수입, 전월 고정비) + 150,000원 + 500,000원`입니다. 총필요 예산을 고정비 사용분과 고정비 외 추가 사용분으로 다른 색으로 표시합니다. 실제 카드값이 고정비 기준보다 낮으면 음수 폭 대신 실제 사용 합계만 채우고 기준보다 적게 사용한 금액을 별도 문구로 표시합니다.
- 예비 자금 그래프는 `월급 여유 자금`(150,000원)과 `월간 비상금`(500,000원) 두 구간(총 650,000원)으로 구분합니다. 각 구간에 사용액과 구간 한도를 표시하며, 고정비가 수입보다 많은 경우 그 초과분도 두 구간 사용액에 포함됩니다. 수입이 고정비보다 많은 경우에는 수입 여유분을 상단에 반영하지 않고 추가 지출 사용분만 두 구간에서 바로 차감합니다. `여유 자금` 항목은 그래프에서 표시하지 않습니다.
- 예비 자금은 월 150,000원과 500,000원(고정비가 수입을 초과할 때는 그 초과분을 차감한 한도)으로 구성합니다. 이를 모두 써도 부족한 상단 기준 초과액을 `미충당 금액`으로 표시하며 통장 잔고에서 자동 차감하지 않습니다.
- 대시보드 요약의 `잔액/저축액`은 `min(전월 수입, 전월 고정비) + 150,000원 + 500,000원 − 총필요 예산`입니다. 음수이면 상단 예비 자금을 모두 사용한 상태이며, 그 절댓값이 `미충당 금액`입니다. 통장 잔고 합계는 이 요약 카드에 별도로 표시하지 않습니다.
- 직접 입력한 통장 잔고는 해당 월에 적용되고, 다음 월에는 같은 잔액을 이월합니다. 직접 입력한 월은 보호합니다. 예상·실제 카드값은 미충당 금액에는 영향을 주지만 통장 잔고에는 영향을 주지 않습니다.
- 대시보드 맨 아래의 `카드결제 이체금`은 선택한 기준월·예상/실제 기준의 실제 부족금액 `max(총필요 예산 − 전월 수입, 0)`을 `1. 월급 여유 자금`(최대 150,000원), `2. 월간 비상금`(최대 500,000원), `3. 추가 지출`(고정비 외 추가 지출 중 65만 원 초과분), `4. 수입·고정비 차액`(`수입 − 고정비`) 순서로 정산합니다. 상단 대시보드에는 반영하지 않았던 `수입 > 고정비` 잔여액과 `수입 < 고정비` 초과분까지 모두 반영해 실제 이체해야 할 `옮길 금액 합계 = max(총필요 예산 − 전월 수입 − 650,000원, 0)`을 계산합니다. 월급 여유 자금(15만 원)은 현금이체를 모두 마친 뒤에도 월급통장에 남아 있고, 월간 비상금(50만 원)은 26일 자동이체되므로 두 항목은 `비상금통장 → 월급통장 (카드결제)` 직접 이체 합계에서 제외합니다. 안내 표시만 추가하며 실제 이체·통장 자동 차감·기존 총계·저장 데이터는 변경하지 않습니다.

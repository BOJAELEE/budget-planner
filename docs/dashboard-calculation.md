# 대시보드 계산 기준

- 청구월의 예상 카드값은 전월 고정비의 카드별 기준 금액과 청구월 미완료 추가지출의 합계입니다. `결재완` 표시한 기록은 목록과 백업에 남지만 추가지출 합계·예상 카드값·히스토리에서 제외되며, `완료 취소` 시 다시 포함됩니다.
- 실제 카드값을 입력한 카드는 그 금액을 사용하고, 미입력 카드는 예상 카드값을 사용합니다. 대시보드는 예상/실제 버튼으로 한 번에 하나의 계산 결과를 표시합니다.
- 예상/실제 선택은 연도·청구월별로 독립적으로 기억합니다. 선택 이력이 없는 달은 실제 카드값 입력 여부와 무관하게 항상 예상으로 시작하며, 다른 달의 선택을 가져오지 않습니다. 직접 실제를 선택한 달만 다시 열 때 실제로 표시됩니다.
- 이 선택은 현재 브라우저에 저장하므로 새로고침·페이지 이동 후에도 유지됩니다. 다른 브라우저·기기로는 동기화하지 않으며 금융 데이터 백업에는 포함하지 않습니다. 브라우저 데이터를 지우면 초기화됩니다. 저장이 차단되거나 저장값이 잘못된 경우에도 대시보드는 동작하며, 저장 실패 시 안내하고 앱을 열어 둔 동안에는 월별 선택을 유지합니다. 이 설정은 화면 표시 기준일 뿐 별도 결산 확정 기능이나 금융 데이터 변경이 아닙니다.
- 대시보드 상단에는 예비자금·사용금액·잔액을 한 줄 세 칸의 통합 요약형으로 표시합니다. 예비자금은 기존 그래프의 가용액 `max(전월 수입 − 전월 고정비, 0) + 150,000원 + 500,000원`, 잔액은 기존 `잔액/저축액` 계산 결과를 그대로 사용합니다. 사용금액은 `예비자금 − 잔액`으로 초과분을 잘라내지 않고 표시하므로, 고정비가 수입보다 많은 경우 그 부족분도 포함합니다. 잔액이 음수이면 마지막 칸의 제목을 `초과금액`으로 바꾸고 음수 금액을 적색으로 표시합니다. 실제 사용이 고정비보다 적으면 음수 사용금액을 그대로 표시해 세 금액의 관계를 유지합니다. 기존 세부 요약·그래프·카드 합계 계산은 변경하지 않습니다.
- 각 결과의 총필요 예산은 전월 현금이체 고정비와 해당 카드값 합계입니다. 부족금액은 `max(총필요 예산 - 전월 수입, 0)`입니다.
- 여유 자금의 월 기준액은 `전월 수입 − 전월 활성 고정비 전체 + 150,000원`입니다. 현금이체와 카드 고정금액을 모두 고정비에 포함합니다.
- 여유 자금 사용액은 `총필요 예산 − 전월 활성 고정비 전체`입니다. 예상·실제 카드값에 따라 각각 계산하며, 사용 후 잔액은 `여유 자금 기준액 − 사용액`입니다. 실제 카드값이 고정 카드 기준보다 낮으면 사용액은 음수로 표시되어 남는 금액에 반영됩니다.
- 여유 자금 사용 후 잔액이 음수일 때 그 부족분을 매 청구월 별도로 적용되는 비상금 500,000원에서 최대 500,000원까지 충당합니다. 사용하지 않은 비상금 한도는 다음 달로 이월하지 않습니다.
- 예산 그래프의 전체 가용액은 `전월 수입 + 150,000원 + 500,000원`입니다. 총필요 예산을 고정비 사용분과 고정비 외 추가 사용분으로 다른 색으로 표시합니다. 실제 카드값이 고정비 기준보다 낮으면 음수 폭 대신 실제 사용 합계만 채우고 기준보다 적게 사용한 금액을 별도 문구로 표시합니다.
- 예비 자금 그래프는 `max(전월 수입 − 전월 고정비, 0)`인 여유 자금, 150,000원, 500,000원을 순서대로 구분합니다. 각 구간에 사용액과 구간 한도를 표시하며, 고정비가 수입보다 많은 경우 그 부족분도 15만 원·50만 원 구간 사용액에 포함합니다.
- 예비 자금은 수입에서 고정비를 뺀 여유분, 월 150,000원과 500,000원으로 구성합니다. 이를 모두 써도 부족한 금액을 `미충당 금액`으로 표시하며 통장 잔고에서 자동 차감하지 않습니다.
- 대시보드 요약의 `잔액/저축액`은 `전월 수입 + 150,000원 + 500,000원 − 총필요 예산`입니다. 음수이면 예비 자금을 모두 사용한 상태이며, 그 절댓값이 `미충당 금액`입니다. 통장 잔고 합계는 이 요약 카드에 별도로 표시하지 않습니다.
- 직접 입력한 통장 잔고는 해당 월에 적용되고, 다음 월에는 같은 잔액을 이월합니다. 직접 입력한 월은 보호합니다. 예상·실제 카드값은 미충당 금액에는 영향을 주지만 통장 잔고에는 영향을 주지 않습니다.
- 대시보드 맨 아래의 `카드결제 이체금`은 선택한 청구월·예상/실제 기준의 부족금액 `max(총필요 예산 − 전월 수입, 0)`을 저축분 사용(최대 150,000원), 월 비상금 사용(최대 500,000원), 추가 충당 순서로 나눕니다. 15만 원 저축분도 이미 비상금통장에 있으므로 세 사용분 모두 `비상금통장 → 카드결제 통장` 이체 합계에 포함합니다. 여유자금은 이미 카드결제 통장에 있으므로 중복해서 더하지 않으며, 사용하지 않은 한도는 이체금에 포함하지 않습니다. 추가 충당은 기존 미충당 금액과 같고, 세 항목의 합계는 부족금액과 같습니다. 안내 표시만 추가하며 실제 이체·통장 자동 차감·기존 총계·저장 데이터는 변경하지 않습니다.
